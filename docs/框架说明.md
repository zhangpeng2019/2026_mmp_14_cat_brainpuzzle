# 框架与猫咪侦探社接入

## 当前正式入口

固定Creator 3.8.7、strict TypeScript，场景流程为 `Boot → Home ⇄ Game`。Boot注册 `BRAIN_PUZZLE_SCHEMA` 后初始化框架；Home展示80关入口和保存同步；Game只启动 `CatDetectiveView`。直接预览Home或Game复用同一套初始化规则。

Game不再导入原版 `main.ts`、GameEntry、GameManager或LevelManager，Home不再提供原版87关入口。共享场景及控制器的既有UUID和绑定保持不变。场景销毁只解绑自己的UI、输入和尺寸监听，不dispose全局Runtime。

## 关卡与资源

| 能力 | 当前实现 |
| --- | --- |
| 关卡定义 | CaseData聚合最初18关及Cases19To40／Cases41To60／Cases61To80，连续编号1—80 |
| 公共契约 | CaseTypes定义对象、操作、依赖、提示与构建辅助函数，避免聚合模块循环依赖 |
| 纯状态机 | CaseSession验证tap／drag／swipe／hold／scrub及先决步骤，支持乱序、撤销、重置和重放恢复 |
| 关卡界面 | CatDetectiveView提供14页案卷、场景交互、提示、笔记、暂停和结算 |
| 道具 | CandyArt及PropArtManifest提供160格真实贴图，无常驻物件标签；外观与命中区分离 |
| 背景与UI | 12张糖果场景、入口插画及2张UI图集，经ResourceLoader加载，资源和meta一并保留 |
| 分辨率 | 项目640 × 1386；内容640 × 1320等比容纳于可用区域，横屏完整显示但缩小 |
| 计时 | CaseClock每关180—360秒，弹层与后台暂停，超时一次免费续60秒或重试 |
| 进度 | catDetective.v1存已结案编号、逐关序列化操作及计时；无法重放的旧进行中记录安全重置对应案件 |

通用 `assets/scripts/framework` 不反向依赖游戏业务。ResourceLoader继续负责并发去重和资源引用；未创建重复全局运行时。新玩法不需要原版87个Bundle或其SDK。

## 存储与云同步

仍使用 `GameStorage → BrainPuzzleRuntime → DataStore`，gameId=`cat_brainpuzzle`，schema为 `BrainPuzzleSave={entries:Record<string,string>}`、version=1。业务值保持字符串序列化，不清空其他应用数据。

首次入口决定Device / Local / Internet模式，后续场景复用，不由Inspector默认值覆盖。Device默认离线可玩。网络配置、登录隔离、CloudSession与FrameworkRuntime契约继续保留。

每个有效步骤、撤销、重置、暂停、切后台及每5秒计时后保存。离关前失败重试，未成功则保留当前案件。恢复通过逐步重放校验动作依赖；损坏记录只重置对应案件。结案记录使用 `Array.from(new Set(...))`，避免Creator发布转换的Set展开兼容问题。零秒与续时标志随档保存，重进不绕过超时。

CandyArt图集切片设packable=false，避免动态图集影响原纹理裁切。Creator节点框外松手可能产生节点TOUCH_CANCEL，输入适配通过公开getEventCode识别原始TOUCH_END；真实取消不提交操作。功能遮罩、进度线与光效可用Graphics，主UI与道具使用Sprite。

## 原版归档与构建边界

原版87关及其专属资源、语言配置、关卡配置、玩法脚本、平台SDK、UI工具和历史验收位于 `archive/legacy-brainpuzzle/`，在Creator的assets扫描和TypeScript include范围之外。既有RF／ccclass／资源UUID原样保存。

归档清单记录11,038个专属文件和23份共享接入快照；共享features／framework／scenes／ui目录元数据留在正式assets并保持旧UUID。`tools/validate-legacy-archive.cjs`核对全部哈希与边界。

`tools/build_web.ps1`只清理经过绝对路径核对的 `build/web-desktop`，防止旧Bundle残留，再启动Creator。`tools/validate-release.cjs`检查实际发布Bundle、注册脚本、旧UUID及压缩形式，并与旧原始资源哈希对照；报告位于 `build/release-isolation.json`。

## 验证

执行 `npm run build:web`、`npm run typecheck`、`npm test`、`npm run test:runtime`。80关模型测试检查459步完整解法与1134种可达状态；真实浏览器逐步解出全部80关，另测五种手势、计时、键盘、存档、美术、错误恢复及视口。

当前证据见 `docs/猫咪侦探社/04-实现与验收.md`。不将旧版历史验收、单纯加载或设计目录当成当前通关证明。
