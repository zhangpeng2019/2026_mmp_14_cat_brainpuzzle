# 框架与玩法接入

基础框架来自用户指定的 2026_mmp_0_cat_framework，参考提交 a93835a7536e7a91a4a30cafc13ae6a185599f05。迁移前已阅读 README、AGENTS.md、框架说明与迁移验收。

## 场景流程

Boot 初始化 FrameworkRuntime 并进入 Home；Home 提供游戏入口和保存同步。GameSceneController 创建 BrainPuzzleRoot 与一个框架 UIManager，再启动原 GameEntry。原 LoadingController 初始化国际化、平台接口、DataManager、教程和大厅；原 GameManager 在 Game 容器内管理大厅及关卡。

右上角返回入口先 flush，再 SceneFlow.goHome。销毁时清理原关卡、计时器、UI 缓存、监听器和框架 UIManager，保留全局数据会话。Home / Game 直接预览也先注册业务 schema 并初始化同一会话。

## 模块接入

| 能力 | 当前实现 |
| --- | --- |
| 场景 | assets/scenes/Boot.scene、Home.scene、Game.scene；Game 保留源场景 UUID |
| 公共资源 | 原 ResourceManager 的 resources Prefab 转接框架 ResourceLoader |
| 关卡资源 | 全部 87 个原关卡目录作为本地 Asset Bundle，所有平台优先本地资源 |
| UI | 原数字层映射到框架 content/effect/modal/toast/loading/hud，不重复创建层树 |
| 坐标 | 框架 Canvas 640 宽，BrainPuzzleRoot 1080 宽等比缩放，高度随 Canvas 调整 |
| 触摸 | 第 1/3 关屏幕增量改为 UI 增量并换算原局部比例，其余保留世界到局部坐标转换 |
| 相机 | 包含 DEFAULT/UI_2D，near=0，保留原 z=1000 的 UI 可见性 |
| 存档 | GameStorage 同步接口 → BrainPuzzleRuntime → DataStore，保留字符串与数值类型 |
| Schema | BrainPuzzleSave={entries:Record<string,string>}，版本 1，运行时校验 |
| 云同步 | 保留 FrameworkRuntime / CloudSession，独立 gameId=cat_brainpuzzle |
| 缓存 | 保留关卡 LRU 与预加载；卸载闲置 Prefab 时保留小型包配置，防止共享请求失效 |
| 物理 | Game 默认关闭；61/72/73 关启动时开启，LevelManager 卸载关卡时关闭共享模拟 |

FrameworkRuntime 的 configure/selectLoginMode/initialize/typedStore/flush/dispose，ResourceLoader 的并发去重和引用持有，以及 UIManager 的实例生命周期契约保持原框架含义。业务不侵入通用 framework 目录。

## 平台与存储

Device 单机为默认，不调用数据服务器。Local 使用回环测试服务；Internet 需设置外网地址及兼容服务。协议仍为 GET/PUT /api/gamedata/game/{gameId}/player/{playerId}，数据按模式、地址、gameId、玩家和平台隔离。

关卡全部随项目本地提供，不依赖原公司的远程关卡服务器。平台 API 和广告后备维持源含义；源中未提供的原生 FunJoy SDK、广告位和真实账号认证不宣称已接通。Web 后备会执行奖励回调，不能当作真实广告播放验证。
