# 糖果美术：道具与角色图集提示词

## 交付与风格

使用内置 `image_gen.imagegen` 生成正规透明PNG，没有调用CLI或Maker，没有用SVG或程序图形代替美术，也没有离线裁剪、抠图或重绘。用户图2作为风格参考：厚实圆润、奶油高光、柔和立体投影，蓝／珊瑚／淡紫／薄荷／金色的休闲猫咪游戏风格。

10张图集共160个格位，全部1254 × 1254，4列 × 4行、行优先索引0—15。实际每格313.5像素，运行时按纹理实际尺寸除以4建立SpriteFrame矩形；每格四周保留透明间距。全部RGBA，alpha范围0—255。资源路径为 `assets/resources/cat-detective/candy/props/sheet-01.png` 至 `sheet-10.png`，各自附有Creator纹理与SpriteFrame元数据。

程序映射位于 `assets/scripts/features/cat-detective/PropArtManifest.ts`，包含全部图格、正式65种kind的映射、显式art别名和角色／物件前后状态选择。文字标签不在图中烘焙；调查文本可以由界面独立显示。

按用户默认要求不做生成后逐张质量检视；已验证文件、尺寸、透明通道和元数据。实际游戏中的清晰度、比例和遮挡由主代理结合新构建验收。

## 正式图集切片修正

生成的图像主体并非严格落在4×4等分格内。正式显示使用PropArtRects.ts记录的160个实际透明主体边界，保留完整猫咪并排除邻格残留；tools/export-prop-rects.cjs从alpha连通主体生成这些SpriteFrame矩形，不修改PNG像素。CandyArt使用该登记且关闭动态图集packable。矩形边界、资源映射及运行时逐关画面另行验证。
