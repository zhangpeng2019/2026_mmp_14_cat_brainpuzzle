# 猫咪侦探社：实现与验收

## 当前交付

正式版本为80关、459个有效步骤、740个对象定义（含替代状态与印章）。单关5—11步、限时180—360秒。详细对象、坐标、前后状态、步骤、三级提示、机制来源见[80关重制设计](09-旧版借鉴与80关玩法重制.md)，目录见[资源复用](08-80关目录与资源复用.md)。

按用户参考图统一为圆润、高光的2.5D糖果卡通风格；UI以蓝色主按钮、奶油色次按钮和深色文字形成清晰层级。实际资源包括12张1122×1402场景、1张887×1774入口插画、2张1254×1254 UI图集、10张1254×1254透明道具图集，共25张PNG、160格道具和状态贴图。场景、入口装饰、按钮与道具使用Sprite；阅读底板、接触阴影、功能遮罩、进度线及光效使用Graphics，没有常驻物件名称Label。未制作角色骨骼动画或配音。详见[界面优化与视觉规范](10-界面优化与视觉规范.md)与[80关陈设审查](11-关卡陈设审查.md)。

原先6张绘本背景及meta移到assets外的archive/cat-detective-v1-art，原87关仍完整保存在archive/legacy-brainpuzzle。正式入口为Boot → Home → 开始调查 → 案卷 → 关卡，Home和Game可直接预览。

## 实现

| 文件 | 职责 |
| --- | --- |
| CaseTypes / CaseData / Cases19To40 / Cases41To60 / Cases61To80 | 80关对象、依赖、状态、时限、真实解法与提示 |
| CaseSession | 纯状态机，验证点击、拖动、滑动方向和距离、长按时长、擦拭距离，支持撤销与重放 |
| CaseClock | 毫秒计时、暂停、到期、一次60秒续时和保存恢复 |
| CatDetectiveView | 14页案卷、五种真实指针输入、键盘等价操作、计时显示、提示笔记及弹层 |
| CandyArt / PropArtManifest | 真实贴图加载、PropArtRects实际主体切片、160格映射，外观缩放与命中区分离 |
| CaseArtLayout | 按背景结构修正陈设，控制小物件比例与角度，枚举可达状态保护输入中心，兼容原存档 |
| CatDetectiveState | catDetective.v1进度及逐关计时记录 |
| FrameworkScreen | 正规美术入口与保存同步界面 |

项目640×1386、fitWidth=true、fitHeight=false；内容640×1320等比完整容纳。横屏会缩小，未制作独立横屏布局。

拖动经过目标不会提前提交，错误落点或真实取消归位。Creator在节点框外松手会发节点TOUCH_CANCEL，现通过公开getEventCode区分原始TOUCH_END与真实取消，保证向框外滑动能提交。擦拭须往复改变方向，长按须真实经过配置时长。

计时只在背景美术加载就绪后的关内运行；提示、笔记、暂停、结案及应用切后台均停止扣时。超时弹层不能通过Esc绕过，可免费续60秒一次或重试；再次超时需重试。计时每5秒及有效操作、暂停、切后台、离关时保存。

存储链路仍为GameStorage → BrainPuzzleRuntime → DataStore，gameId=cat_brainpuzzle，保留字符串及业务键catDetective.v1。旧档没有timers可读取；已结案记录保留，无法按重制后依赖重放的旧进行中记录仅重置对应案件。写入失败显式提示重试并保留现场。零秒及已续时状态保存后不能通过重进绕过。

## 归档与发布边界

原87关共11,038个专属文件（576,866,035字节）及23份共享接入快照，SHA256逐项一致。构建清理仅针对经绝对路径核对的build/web-desktop。实际Bundle仅internal、main、resources；61个产物JSON无旧UUID及其压缩形式共24,558种命中，92个发布文件对照4,591种旧原始资源哈希无命中。原版脚本注册器和Level Bundle不进入正式发布。

未发布线上服务，未提交推送Git。

## 复跑

```powershell
npm ci
npm run build:web
npm run typecheck
npm test
npm run test:runtime
```

可单独执行npm run test:archive、npm run test:release、npm run test:detective。node tools/export-case-catalog.cjs从正式数据重新生成80关目录。资源生成提示词和实际路径见糖果美术的场景与UI、道具两份文档。
