# 猫咪侦探社：第 07—18 关设计

这十二关与首批六个代表关共同构成 18 个制作目标。动作、依赖与对象可见性对应 `CaseData.ts`；所有步骤的完整三层提示同样保存在该数据中。此文提供各关可交接的设计解释、标准路径、关键提示和资源需求。是否完成真实构建与指针通关，以最终验收记录为准。

## 第 07 关：雨夜脚印

- **场景：**雨后小巷，脚印从墙边通向排水格栅。背景复用 `alley.png`。
- **目标与独特推理：**先保护会被环境破坏的证据，再用侧光读出浅痕。主线不设真实倒计时，避免未理解规则就失去证据。
- **初始对象：**旧雨伞、渐淡脚印、手电、排水口；避雨小猫隐藏。
- **标准步骤：**旧雨伞拖到脚印 → 手电拖到脚印 → 根据延伸方向点击排水口，小猫出现。
- **依赖与反馈：**必须先挡雨再照明；直接点排水口只能读到格栅边毛发描述，不能提前救猫。雨伞和手电提交后离开待用位置，防止重复计数。
- **关键三层提示：**「证据快被雨冲走了」→「先用能挡雨的东西保护脚印」→「把旧雨伞拖到渐淡脚印」。完成保护后改为侧光提示，最后提示格栅毛发。
- **美术需求：**雨伞、两阶段脚印、手电、排水格栅、橘色毛发和小猫；增强版加入雨丝、伞下干区、侧光足迹线，雨势不能遮住命中对象。
- **结案与验收：**小猫获得干毛巾。测试提前照明无进度、脚印可重复观察、取消拖伞恢复原位，以及完整三步解法。

## 第 08 关：阁楼回声

- **场景：**侦探社阁楼，暖气管穿过墙体，通风格栅后有叫声。复用 `office.png`，以管道前景解释阁楼区域。
- **目标与独特推理：**金属管传声帮助定位，再由猫助手确认，最后使用工具打开遮挡。
- **初始对象：**金属勺、暖气管、猫助手、通风口、螺丝刀；墙后幼猫隐藏。
- **标准步骤：**金属勺拖到暖气管 → 猫助手拖到通风口 → 螺丝刀拖到通风口。
- **依赖与反馈：**敲击先得到「右侧回应」，听声确认后才拆格栅；螺丝刀不能在未确认位置时提前救猫。声音必须有可见字幕／波纹等价信息。
- **关键三层提示：**「让听力更好的伙伴确认方向」→「猫助手能分辨墙后的声音」→「把猫助手拖到通风口」。
- **美术需求：**勺、金属管、格栅、螺丝刀、猫助手与幼猫；增强版提供管道振动线、右侧声波、猫耳朝向、格栅拆下状态。
- **结案与验收：**幼猫获救，阁楼承诺加安全网。测试静音可读性、未听声先拆的反馈，以及格栅打开后旧来源与工具的退场。

## 第 09 关：停摆的花钟

- **场景：**阳光房与花园门前，花钟缺水又被遮棚挡住。复用 `sunroom.png`。
- **目标与独特推理：**花钟需要水、光和正确时刻三个条件，其中水与光是独立支线。
- **初始对象：**水壶、干燥花盆、遮阳棚、花钟表盘；盛开的花钟隐藏。
- **标准步骤：**水壶拖花盆、点击遮阳棚，两者可交换顺序 → 点击表盘，归到正午，花钟展开。
- **依赖与反馈：**只给水或只给光时不能开花；表盘在条件未齐时不改变进度。增强版通过花苞抬头与光斑分别确认两支线完成。
- **关键三层提示：**「水和阳光齐了，还差时间」→「把花钟调到阳光最好的正午」→「点击花钟表盘」。
- **美术需求：**水壶、干土／湿土花盆、遮棚、花钟表盘、闭合／盛开花瓣、小门状态；提示中正午与表盘档位必须对应。
- **结案与验收：**小门打开，蝴蝶飞来。测试水先与光先两种路径，缺任意条件不得结案，完成后花钟和印章可见。

## 第 10 关：谁动了车票

- **场景：**集市旁的渡船候船点，车票在失物箱被好心人代领。复用 `market.png`，用站钟和记录形成候船区前景。
- **目标与独特推理：**把「有空代领」的时间条件与线头物证交叉验证；站钟校时记录用于确认时间可信。
- **初始对象：**代领记录、站钟、蓝色线头、蓝围巾客、红衣客、绿帽客。
- **标准步骤：**三证据可任意顺序读取 → 点击蓝围巾客确认。
- **证据链：**代领发生 9:50；红衣客 9:55 才进站，绿帽客 9:30 已离站；蓝围巾客 9:40 已在站内。箱沿蓝线与围巾缺口相符，时间与物证一致。
- **关键三层提示：**「同时满足时间和线头证据的是谁」→「九点五十在站内，还戴着蓝围巾」→「点击蓝围巾客」。
- **美术需求：**失物代领记录、校准站钟、线头放大图、三人／服饰标记；不能仅靠衣服颜色识别，围巾形状与线头缺口也要可见。
- **结案与验收：**代领者一直等失主，票归原主。测试六种证据读取顺序、提前选对者不结案、错误选择给出时间矛盾且保留证据。

## 第 11 关：倒着看的招牌

- **场景：**画廊版画展，收藏箱上的符号被反写。复用 `gallery.png`。
- **目标与独特推理：**先用镜子还原方向，再按可读的符号顺序输入。提示牌提供规则来源。
- **初始对象：**镜像招牌、手镜、反写符号、月亮钮、猫爪钮、星星钮。
- **标准步骤：**点击招牌 → 手镜拖到反写符号 → 按月亮、猫爪、星星顺序点击。
- **依赖与反馈：**未反射前猜符号不能绕过观察；顺序要求明确，错误点按不抹除已读规则。输入后每钮逐步亮起，下一步反馈可回看。
- **关键三层提示：**「反写符号需要反射一次」→「手镜能还原方向」→「把手镜拖到反写符号」。后续分层提示对应下一个符号。
- **美术需求：**手镜、反写／正向符号板、三种独立形状按钮、收藏箱开闭状态；反射后的顺序要在反馈和符号图层中都能读到。
- **结案与验收：**箱中找回倒印版画。测试先点星星或猫爪不能推进，正确顺序可逐步完成；撤销一次仅退回最近一个已亮按钮。

## 第 12 关：失踪的末班车

- **场景：**钟楼内的旧交通控制平台，末班车在隧道等待信号。复用 `clocktower.png`，控制设备作为独立前景。
- **目标与独特推理：**路线必须先确认安全，才能发出放行信号；电源、道岔与信号各有职责。
- **初始对象：**备用电池、控制箱、轨道图、支线开关、信号灯。
- **标准步骤：**读取轨道图 → 电池拖到控制箱 → 点击支线开关切主线 → 点击信号灯放行。
- **依赖与反馈：**读图前无法提交电源步骤，通电前开关不响应，路线未正确时信号灯不能放行。无效尝试不会造成真实列车碰撞或强制重开。
- **关键三层提示：**「绿灯亮起前先确认路线」→「当前开关还指向支线」→「点击支线开关」。
- **美术需求：**电池、接口、轨道图、主／支线开关、信号灯两态、进站列车远景；线路同时用形状与方向标识，不能只靠红绿。
- **结案与验收：**末班车安全进站，司机致谢。测试提前开信号不会结案，撤销切线恢复支线，重开不残留绿灯完成态。

## 第 13 关：双份早餐

- **场景：**早晨的侦探社，两个碗都空了，明明只见一只猫。复用 `office.png`。
- **目标与独特推理：**用痕迹差异推断第二位食客，再借少量粉末让浅湿爪印显形。
- **初始对象：**两个空碗、面粉袋、窗台、短窗帘；小访客隐藏。
- **标准步骤：**点击空碗比较胡须痕 → 面粉拖到窗台 → 沿显出的脚印点击短窗帘。
- **依赖与反馈：**先观察数量与痕迹，再显迹；直接掀帘只能反馈需追踪来路，不提前获胜。面粉处理一次到位，不模拟可无限倒粉的清洁负担。
- **关键三层提示：**「脚印很浅，怎样让它显出来」→「少量粉末能显出湿爪印」→「把面粉袋拖到窗台」。
- **美术需求：**两个不同胡须痕的空碗、面粉袋、窗台湿印／显印、短帘、小猫；痕迹大小差异需清晰，不能只在文字里出现。
- **结案与验收：**为新朋友准备第三只碗。测试未看空碗不能显迹、显迹后脚印方向与窗帘位置一致、撤销掀帘恢复隐藏猫。

## 第 14 关：风中的信

- **场景：**小巷栏杆旁，信落在伸手够不到的一侧，附近有小风扇和轻托盘。复用 `alley.png`。
- **目标与独特推理：**同时准备「正确的推力」与「稳定的落点」，避免只把信吹到别处。
- **初始对象：**圆镇纸、轻托盘、小风扇、栏杆风口、栏杆外的信；就位风扇和安全的信隐藏。
- **标准步骤：**镇纸拖托盘、风扇拖风口，两者可交换顺序 → 点击就位风扇，信落进托盘。
- **依赖与反馈：**风扇已就位但托盘未固定时不能启动成功；两项准备都完成才让信转移。首批不让信被吹丢形成死锁。
- **关键三层提示：**「先准备稳定的落点」→「托盘太轻，需要压住」→「把圆镇纸拖到轻托盘」。
- **美术需求：**镇纸、轻托盘、风扇未安装／安装、栏杆与风口、信前后位置；增强版提供风向线和落信轨迹。
- **结案与验收：**给猫奶奶的信完整取回。测试两种准备顺序和提前启动；撤销最后一步信必须回到栏杆外，不同时存在两封信。

## 第 15 关：温室迷雾

- **场景：**潮湿温室，玻璃起雾挡住送货牌，地上潮便条只辨出「三格」。复用 `sunroom.png`。
- **目标与独特推理：**先消除持续起雾的原因，再处理已有水汽，最后结合两条信息读出位置。
- **初始对象：**天窗开关、干抹布、起雾玻璃、潮湿便条；清晰送货牌隐藏。
- **标准步骤：**点击天窗开关通风 → 抹布拖玻璃擦净 → 点击清晰送货牌，读出东门第三格。
- **依赖与反馈：**未通风先擦不能持久显牌；便条只是辅助信息，完整地点必须从清晰牌读取。擦拭采用整次拖放，避免高频擦屏造成疲劳。
- **关键三层提示：**「擦完又起雾，原因是什么」→「先让湿空气离开温室」→「点击天窗开关」。
- **美术需求：**开关、天窗开闭、玻璃雾层／清晰层、抹布、送货牌、潮便条；关键文字由引擎绘制，玻璃目标命中区扩大。
- **结案与验收：**货箱送达，幼苗得到新花盆。测试先擦不提前显示牌，撤销擦拭恢复雾玻璃，未点击清晰牌不结案。

## 第 16 关：午夜送货人

- **场景：**夜市仓库前，一箱匿名猫粮在午夜前送到。复用 `market.png`。
- **目标与独特推理：**工作时间、运输工具和包装材料三条件交叉确认好心邻居。
- **初始对象：**仓库出库单、单轮车印、黄色绑绳、鼹鼠车夫、兔子邮差、小狗快递员。
- **标准步骤：**三证据任意顺序读取 → 点击兔子邮差确认。
- **证据链：**23:50 最后出库对应兔子，小狗 22:00 已下班；现场单条车辙排除双轮车的鼹鼠；黄绳编法与兔子车上的相同，小狗是蓝绳。
- **关键三层提示：**「三项条件必须同时满足」→「谁在 23:50 出库，还使用黄绳单轮车」→「点击兔子邮差」。
- **美术需求：**出库单、单／双轮车形状卡、绑绳及编法放大图、三位角色；绳子以编法补充颜色辨认。
- **结案与验收：**猫咪们给兔子画感谢卡。测试错误居民排除理由、未集齐证据无法结案、已读证据重复点按不重复计数。

## 第 17 关：月亮掉进井里

- **场景：**画廊庭院的井旁，小猫误以为月亮掉进水里。复用 `gallery.png` 作为展览区域基底，井水与天空月亮为独立交互层。
- **目标与独特推理：**用可重复观察的环境实验，区别实体与倒影。
- **初始对象：**井中月影、小石子、井水、半块井盖、天空月亮、困惑小猫。
- **标准步骤：**小石子拖井水，月影被波纹打散 → 半井盖拖到月影，水面反光被遮住 → 点击天空月亮确认真正位置。
- **依赖与反馈：**先观察波纹的变化，再做遮光对照；天空月亮一直可见，但提前点不能跳过实验。石子落点只在井水范围接受，不触及猫。
- **关键三层提示：**「遮住水面，看看天空有没有变化」→「井盖能挡住反射的光」→「把半块井盖拖到井中月影」。
- **美术需求：**井沿、水面、月影、天空月亮、半井盖、石子、困惑猫；增强版波纹让倒影短暂碎开再聚合，井盖遮住后月影消失。
- **结案与验收：**小猫理解倒影。重点检查月影与井水的命中区分离，拖石子能落到井水；撤销遮光后倒影恢复；天空月亮从始至终没有被移走。

## 第 18 关：灯塔最后一夜

- **场景：**暴风雨前的灯塔，归船等待引航。复用 `clocktower.png` 的塔内结构，以灯座、镜面和备用设备形成灯塔前景。
- **目标与独特推理：**供电、发光、定向与发送信号缺一不可；备件搜索可与恢复电源并行。
- **初始对象：**值守手册、蓄电池、备用电源口、备件柜、空灯座、偏转反光镜、信号按钮；备用灯泡隐藏。
- **标准步骤：**读手册 → 电池拖电源口；独立点击备件柜找到灯泡 → 电源和灯泡均齐后，灯泡拖空灯座 → 点击反光镜转向海面 → 依次点击信号按钮三次。
- **依赖与乱序：**备件柜可以在读手册／通电前打开；灯泡安装需要已通电且取到灯泡；镜面未朝海不能发信号；三次信号每次是独立状态，不用毫秒级节拍。
- **关键三层提示：**「方向正确，可以发送信号了」→「手册要求三次」→「点击信号按钮，发送第一次」。之后提示明确已发次数与剩余次数。
- **美术需求：**手册、电池、备用接口、备件柜开闭、灯泡、空／亮灯座、镜面两个朝向、按钮、三次光信号与小船回应；声音配字幕，不是唯一完成依据。
- **结案与验收：**全部小船归航，小镇来信致谢。测试柜子提前打开的合理路径、只按一／两次不结案、快速重复点击必须逐次合法提交、撤销最后闪光仅退回一次。

## 首批三章结构

| 案卷页 | 关卡 | 体验节奏 |
| --- | --- | --- |
| 初识小镇 | 01—06 | 认识观察、道具、机关、证据、脑洞与综合流程 |
| 循迹追光 | 07—12 | 环境保护、传声、独立条件、时间推理、镜像与安全顺序 |
| 午夜来信 | 13—18 | 痕迹比较、落点准备、消除原因、条件交叉、实验验证和多条件收束 |

18 关共用六个场景族，但关键推理与操作依赖不同。后续试玩应关注玩家是否理解因果、是否需要反复盲点、提示能否解释卡点，并据实际表现调整线索强度。
