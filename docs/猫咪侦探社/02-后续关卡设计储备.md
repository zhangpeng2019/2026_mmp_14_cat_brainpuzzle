# 猫咪侦探社：第19—36关最初设计草案

本文保留最初19—36关的设计思路。当前这些关卡已进入正式80关版本，实际步骤、对象与提示以[19—40实现设计](05-第19至40关实现设计.md)及CaseData为准。完整当前内容见[80关目录](08-80关目录与资源复用.md)，本文件不再表示待制作范围。

## 第 19 关：不该响的门铃

- **场景与目标：**雨后小巷，住户称无人按铃却不断响。查明原因并恢复安静。
- **独特推理：**门铃声与屋檐水滴同步，原因来自水导通而非隐藏的人。
- **步骤：**观察铃线接头水珠 → 打开雨棚排水口，让水流改道 → 用干布擦干接头 → 合上绝缘罩并试铃。
- **提示：**「听听响铃前发生了什么」→「水落在了裸露的接头上」→「先疏通排水，再擦干接头、盖好罩」。
- **反馈与边界：**只擦不排水会再次变湿并说明原因，不回退已发现线索；顺序错误可恢复。
- **资源：**复用 alley；新增水滴节奏、裸接头／干接头、排水口开闭、绝缘罩和布。

## 第 20 关：两把一样的钥匙

- **场景与目标：**侦探社收到两把外形相同的钥匙，找出能打开档案盒的一把。
- **独特推理：**不能只看钥匙轮廓，锁芯留下的蜡印能提供凹槽信息。
- **步骤：**打开盒底检修盖找到说明 → 将软蜡片压到锁孔入口取得轮廓 → 在放大台比较两把钥匙的凹槽 → 选择相符钥匙开盒。
- **提示：**「正面看起来一样，侧面呢」→「锁孔可以留下形状信息」→「用蜡片取印，比较中段凹槽」。
- **反馈与边界：**错误钥匙只转不动，不能折断；比较视图不要求像素级辨认。
- **资源：**复用 office；新增档案盒、两把可辨凹槽钥匙、蜡片两状态、放大比较图。

## 第 21 关：看不见的墨水

- **场景与目标：**温室主人收到一张空白便笺，找出安全的处理方法并读出留言。
- **独特推理：**柠檬气味和写字压痕提示可温热显字，热源不是用火烧纸。
- **步骤：**斜光观察压痕 → 检查桌边柠檬与说明卡 → 将便笺放在温热灯罩旁的纸架上 → 调整距离至安全标记，显出约定地点。
- **提示：**「空白纸上也可能有痕迹」→「柠檬写过的字遇温热会变化」→「把纸放到台灯旁的纸架，保持安全距离」。
- **反馈与边界：**靠得过近时自动退回安全位置，不销毁纸条；显字不依赖真实等待很久。
- **资源：**复用 sunroom；新增压痕纸／显字纸、柠檬、纸架、距离标记和灯罩暖光。

## 第 22 关：错位的合影

- **场景与目标：**集市寻物公告中有一张被换过的合影，找出被修改的位置。
- **独特推理：**影子方向与人物遮挡关系暴露拼接，外貌不是判断依据。
- **步骤：**观察真实广场太阳方向 → 把合影放到透光板 → 标出逆向影子与不可能的前后遮挡 → 选择被拼入的人像，找到背面原始照片编号。
- **提示：**「看看脚边」→「同一地点的阳光方向应一致」→「标出向光源伸去的影子，再核对遮挡」。
- **反馈与边界：**只找到一处时允许继续观察；错误标注可取消。
- **资源：**复用 market；新增合影前后版、透光板、可选影子标记和编号卡。

## 第 23 关：猫走过的书架

- **场景与目标：**画廊休息室的书架后有猫叫，打开隐藏检修门。
- **独特推理：**书脊灰尘与连续爪印给出抽书顺序，顺序来自痕迹而非猜密码。
- **步骤：**拂去书架侧板灰尘 → 对照从低到高的爪印与书脊符号 → 按爪印路径依次拉出三本书 → 推开已解锁侧板。
- **提示：**「墨团最近爬过这里」→「爪印连起了三本书」→「沿从低到高的路径拉动对应书脊」。
- **反馈与边界：**拉错后书回弹，保留已找到的爪印，不扣时。
- **资源：**复用 gallery；新增书架局部、三书拉出状态、灰尘遮罩、爪印路径和检修门。

## 第 24 关：第二声钟响

- **场景与目标：**钟楼发出两个不同音高的钟声，找出松动的共振片。
- **独特推理：**通过可视振幅和顺序定位声音来源，不能只靠音高辨识。
- **步骤：**轻敲测试锤 → 观察四片共振板的振动波纹 → 用软夹固定疑似松板再测试 → 拧紧固定后恢复正常单声。
- **提示：**「钟声后哪一片还在动」→「多余的声音来自未固定的板」→「先夹住持续振动的那片，确认后拧紧」。
- **反馈与边界：**夹错可取下；静音时仍可凭波纹完成。
- **资源：**复用 clocktower；新增四片板、软夹、螺丝、振幅动画及两次测试反馈。

## 第 25 关：借来的雨伞

- **场景与目标：**侦探社失物架上三把雨伞，找出属于留言者的一把。
- **独特推理：**留言包含行程与天气，伞面附着物比颜色描述可靠。
- **步骤：**读「经过花店，未走河边」留言 → 检查伞面花粉／泥点／河草 → 用放大镜确认花粉与花店样本吻合 → 将相符雨伞交到归还架。
- **提示：**「想想他经过了哪里」→「伞面留下了路线的痕迹」→「比较花粉样本，归还带同种花粉的伞」。
- **反馈与边界：**错误归还会列出路线矛盾，物品留在架上。
- **资源：**复用 office；新增三伞、花粉放大图、路线留言、归还架。

## 第 26 关：被风改写的路标

- **场景与目标：**小巷岔路的旋转路标指错方向，帮迷路居民找到车站。
- **独特推理：**螺栓磨痕与地面旧基座提供原朝向，地图北向要先校正。
- **步骤：**读地图与北向图标 → 观察墙上日晷定位东侧 → 旋转路标使磨痕与基座吻合 → 固定螺栓并指向车站路线。
- **提示：**「路标本身可能转过」→「底座留下了原来的方向」→「校正北向，让磨痕对齐后固定」。
- **反馈与边界：**支持分档旋转，方向同时用箭头与文字表达。
- **资源：**复用 alley；新增三叉路标、旧基座、日晷、可旋地图与螺栓。

## 第 27 关：会撒谎的温度计

- **场景与目标：**温室温度显示过高，却没有植物萎蔫，检查读数来源。
- **独特推理：**温度计靠近局部热源，测量位置影响读数。
- **步骤：**比较室内两株植物状态 → 发现温度计紧贴暖水管 → 移到通风阴影处挂钩 → 等待读数稳定后设置合适通风档位。
- **提示：**「测到的是哪里的温度」→「旁边的管道会加热它」→「把温度计移到阴影挂钩，再调整通风」。
- **反馈与边界：**稳定过程以短动画完成；不要求现实温度知识，场景附说明牌。
- **资源：**复用 sunroom；新增温度计刻度、暖管热纹、挂钩、通风档位。

## 第 28 关：三封同一天的信

- **场景与目标：**集市信箱里三封信都写「今天到」，找出真正最新的委托。
- **独特推理：**信内相对日期不可靠，邮戳和可见日历才是绝对依据。
- **步骤：**读取三封信的承诺 → 翻看邮戳日期 → 对照集市活动日历确定延误 → 将真正当天投递的信放入急件格。
- **提示：**「今天是谁的今天」→「比较信外面的日期」→「按邮戳与日历选最新投递的一封」。
- **反馈与边界：**日期使用清晰月日，全部证据同时可看，避免记忆负担。
- **资源：**复用 market；新增三信前后、邮戳放大图、活动日历、急件格。

## 第 29 关：只亮一半的星图

- **场景与目标：**画廊星图投影缺一半，修复展示并找出隐含坐标。
- **独特推理：**两张互补透明片需要在同一基准点叠合，不能只旋转灯。
- **步骤：**检查两张半幅透明片 → 将圆点标记对齐 → 旋转第二片使轮廓连续 → 投影完整星座，读取指向的展柜编号。
- **提示：**「缺少的部分可能在另一张上」→「先对齐圆点，再看轮廓」→「叠合透明片并旋转到星线连续」。
- **反馈与边界：**提供吸附角度和形状标记，不能靠颜色叠加作为唯一解法。
- **资源：**复用 gallery；新增投影仪、两透明片、完整星图、展柜编号。

## 第 30 关：迟到一分钟

- **场景与目标：**钟楼与车站时间差一分钟，找出哪一只钟需要校准。
- **独特推理：**用独立报时记录比较两个来源，不能默认主钟正确。
- **步骤：**读取车站发车记录 → 播放有时间标记的广播报时 → 比较钟楼与车站时针 → 只校准偏差的那只钟并试报时。
- **提示：**「需要第三个时间来源」→「广播有独立时间标记」→「对照报时记录，校准多走一分钟的钟」。
- **反馈与边界：**时间以游戏内记录为准，不读取设备系统时间；可重复播放报时字幕。
- **资源：**复用 clocktower；新增双钟面、广播机、记录表、校准旋钮。

## 第 31 关：窗上的第二只猫

- **场景与目标：**侦探社窗上出现「第二只墨团」，判断是真猫还是影像并找到声源。
- **独特推理：**反射随视角和遮光变化，声音可能来自窗外另一处。
- **步骤：**移动台灯观察倒影同步 → 拉半边窗帘遮住反光 → 发现窗外阳台上的真猫 → 打开安全小门引导它进入。
- **提示：**「两只猫是否完全同步」→「遮住反光后再看窗外」→「拉帘区分倒影，打开阳台小门」。
- **反馈与边界：**不把窗外猫引向危险边缘；开窗前给出安全门结构。
- **资源：**复用 office；新增窗反射层、半帘、阳台猫、安全小门。

## 第 32 关：没有锁的箱子

- **场景与目标：**小巷包裹箱没有锁孔却打不开，安全取出误装进去的玩具。
- **独特推理：**不是找钥匙，箱内压差与气孔堵塞才是原因。
- **步骤：**观察箱盖密封圈 → 查看运输标签上的通气图标 → 移开堵住通气孔的贴纸 → 听到泄压声后打开箱盖。
- **提示：**「它可能不是被锁住了」→「检查空气能否进出」→「揭开通气孔上的贴纸，再掀盖」。
- **反馈与边界：**暴力撬动只反馈阻力，不生成破坏失败；贴纸边角有可揭线索。
- **资源：**复用 alley；新增密封箱、运输标签、贴纸揭开状态、气流符号和玩具。

## 第 33 关：夜里开的花

- **场景与目标：**温室夜间展览的一株花不开，找到适合它的环境。
- **独特推理：**植物说明表明需要黑暗与水分，不能沿用此前「给光」解法。
- **步骤：**阅读夜开花照护卡 → 检查土壤干湿 → 适量浇水 → 遮住直射灯并保留步道灯，花瓣展开露出展览印章。
- **提示：**「这种花什么时候开」→「照护卡写的是黑暗与湿润」→「浇水后遮住直射灯，保留安全照明」。
- **反馈与边界：**多浇一次不会淹死，浇水到位自动停止；规则变化由说明卡明确预告。
- **资源：**复用 sunroom；新增夜开花闭合／展开、照护卡、土壤状态、遮光板。

## 第 34 关：谁先到集市

- **场景与目标：**三位居民对排队顺序各执一词，恢复公平顺序。
- **独特推理：**每条证据提供偏序关系，通过共同事件串成时间链。
- **步骤：**读取「面包出炉前」「钟响后」「送货之前」三条证言 → 对照烤炉、钟、送货记录 → 将居民卡放入三格时间轴 → 提交并显示因果链。
- **提示：**「先确定共同发生的事情」→「把每个人放到事件前后」→「按记录建立事件顺序，再排列居民」。
- **反馈与边界：**错误提交指出一条矛盾关系；卡片可交换，不重置已读证词。
- **资源：**复用 market；新增三居民卡、三事件记录、时间轴三格、关系连线。

## 第 35 关：画里的风向

- **场景与目标：**画廊修复师把三块画布装错方向，恢复能自洽的景象。
- **独特推理：**旗帜、烟和树叶必须受同一风向影响，按画面关系判断旋转。
- **步骤：**固定不可旋转的风向标片 → 分别旋转旗帜、烟、树叶画布 → 核对地平线与风向同时连续 → 锁定画框得到签名。
- **提示：**「看不见的风留下了哪些影响」→「旗、烟、树叶应朝同一方向」→「以风向标为准旋转三块画布，再核对地平线」。
- **反馈与边界：**每次旋转 90 度并可撤销；避免仅靠边缘图案拼图即可跳过主推理。
- **资源：**复用 gallery；新增四块画布、旋转把手、风向标、完成签名。

## 第 36 关：小镇的第一封回信

- **场景与目标：**终章回到钟楼，恢复夜间邮灯，把此前居民的回信送出。
- **独特推理：**综合识别来源、建立供能和校正方向，三个独立条件共同形成可靠信号。
- **步骤：**用邮戳与路线卡找出正确邮件袋 → 按安全标志接通邮灯供电 → 通过镜面把光引到屋顶信号板 → 按此前学过的长短信号发出通知 → 将邮件袋交到已确认到站的邮车。
- **提示：**「邮件、灯和邮车都需要确认」→「先确认信件来源，再让信号能被看见」→「核对邮戳、接电、转镜、发送标记节奏，最后交袋」。
- **反馈与边界：**前三条支线可合理乱序；交袋前必须确认邮车标识；信号用字幕与图形同步展示。
- **资源：**复用 clocktower 及 office/market 的纸面资产；新增邮件袋、屋顶信号板、邮车远景、灯光路径与小镇居民回信画面。

## 扩展制作前检查

第 19—36 关正式进入制作前，应先以简单形状验证标准解法、错误反馈与无死锁，再生成新增道具状态。涉及声音、日期、方向和颜色的关卡必须提供可见的等价信息。复杂序列至少保留一个有效的中途恢复点。

这些关卡的独特推理分别涉及导通、轮廓、温热、投影、路径、共振、附着物、方向、测量位置、绝对日期、叠合、独立校时、反射、气压、条件反转、偏序、风向一致和综合传递，后续审核以此检查是否退化成重复点击。
