# 猫咪侦探社美术资源与提示词

本批使用内置 `image_gen.imagegen` 逐张生成6张正式场景背景，未使用 CLI 或外部 API 密钥。生成原图复制进工程，保留原始生成文件。背景为不透明PNG，不做抠图处理。

六张实际输出均为 **1182 × 1330**，已检查PNG文件头和文件存在性；正式显示效果由工程重建后的运行时验收确认。

## 美术统一规范

- 温暖绘本手绘2D，奶油纸质、墨蓝描线、鼠尾草绿和暖橙色点缀。
- 纵向近方形构图，中下部保留可读空间，由引擎叠放物件、线索、角色与反馈。
- 文字、UI、可移动道具、关键线索均不烘焙进背景；环境固定装饰尽量放在边缘。
- 背景通过 Cocos Creator 的 `SpriteFrame` 资源加载，图像、纹理和精灵帧子资源元数据一起交付。
- 原图保持生成尺寸，运行时统一缩放到关卡棋盘；不是可直接点击的整幅谜题图。
