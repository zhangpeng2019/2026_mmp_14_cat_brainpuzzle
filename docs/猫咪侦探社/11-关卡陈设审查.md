# 80关陈设与美术审查

本轮审查覆盖全部80关、740个对象定义及1134种合法可达状态。以12张正式场景的真实结构为依据，保留谜题对象ID、步骤ID、显隐条件、存档格式和事件层级。陈设适配由 `CaseArtLayout.ts` 提供，原始关卡数据保留。

## 全局处理

- 原有555个对象共用默认命中尺寸，且未设置摆放角度或视觉比例。本轮让可拾取纸张、手工具和小型散物有轻微角度与更克制的视觉比例，角色、安装件、方向线索与覆盖层保持正向。旋转后的最坏矩形包围盒仍容纳在原命中框内。
- 只移动有明确背景依据的第1、2、13关物件：办公桌与窗边、巷道地面的猫篮、阁楼的真窗与灯位。其它关卡保留交互坐标，通过贴图比例、接触阴影与轻微角度改善陈设。没有根据的坐标不作随机挪动。
- 状态替换沿用共同位置；不会对交互节点按纵坐标重新排序。第3、17、18关固定光束、波纹等关联坐标保留。
- 第1关抽屉显式采用抽屉贴图，纠正原来的粉色箱子。第13关空灯座与暖灯显式使用灯具贴图，规避“没有灯泡”文案误命中灯泡映射；漏雨水滴缩小。
- 第13关地面积水由主视图绘制低矮半透明水面与反光；`Artwork` 保留真实Sprite并淡化。落地类物件的接触阴影由主视图/美术组件统一处理，悬挂件、发光件、水滴、灰尘、玻璃覆盖层与标记排除。
