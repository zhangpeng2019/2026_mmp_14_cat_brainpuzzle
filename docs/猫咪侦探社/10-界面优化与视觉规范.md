# 界面优化与视觉规范

本轮优化保留糖果小镇插画、蓝色糖果按钮与猫耳入口，统一解决按钮尖角、宽度失控、浅字不清、装饰遮字及部分物件悬浮的问题。参考 `E:/Github/game_refer/02.ui_ux_design` 中的阅读对比、主次行动、留白、九宫格和真实输入原则；分辨率继续采用本工程的640×1386，侦探社内容640×1320。

## 组件规则

| 元素 | 实现与用途 |
| --- | --- |
| 主按钮 | 蓝色糖果贴图、深色粗体文字；入口336×80，提示176×80，弹窗344×80 |
| 次按钮 | 奶油色贴图、深色文字，视觉强度低于主按钮；入口304×80 |
| 九宫格 | 在原图坐标下保留边角，再按目标高度缩放子节点，仅延展中心；不把原图边距直接压进矮按钮 |
| 阅读底板 | 奶油色、细边框、轻接触投影，圆角统一；案卷、标题、对白与弹窗不使用带音符、爪印的装饰图作文字底 |
| 文字颜色 | 正文RGB(42,58,79)，辅助RGB(86,101,119)，调查强调RGB(35,100,119)；危险提示RGB(167,58,64) |
| 字号 | 正文与操作24左右，辅助18—23，标题36—46；中文允许合理换行，运行时检查缩小后的字号下限 |
| 按压与忙碌 | 按压100毫秒、缩放至96%；入口忙碌时禁用按钮并降低透明度，显示当前操作文案 |

按钮与阅读底板分别由 `DetectiveDrawing.actionButton` 和 `DetectiveDrawing.paper` 统一提供。入口装饰面板仍来自真实Sprite；需要阅读的区域使用引擎绘制的简洁底板。图片和文本分别渲染。

按定义的RGB颜色计算，正文对奶油底的对比度为11.10:1，辅助文字为5.72:1。糖果按钮包含渐变，另以本次实际截图检查文字与高光、边缘的关系。

## 页面调整

- 入口：插画人物保持在上半区，标题与说明放入独立底板；开始调查为唯一主要行动；保存同步缩短为次按钮。保存状态与反馈集中到下方阅读区。
- 案卷：三列两行统一卡片，图片、编号与类别、关卡名、调查状态依次排列；删除拉伸的装饰卡框。场景预览等比覆盖并裁切，不再横向挤压原画。页码、翻页和返回入口各有独立空间。
- 解谜：返回与笔记位置统一；时间使用安静底板。关卡标题和目标集中到顶部，场景画框收窄，调查手记有独立标题与正文区。底部撤销、线索提示、重玩、暂停明确分级，暂停显示文字。
- 弹窗：标题、正文与行动留出固定间距，背景遮罩阻挡底层输入；主要行动先显示，次要行动使用奶油色。保留既有键盘焦点与Esc规则，超时仍不能绕过。

## 陈设与美术

全部80关按对象定义、背景结构和可达状态审查；详细记录见 [11-关卡陈设审查](11-关卡陈设审查.md)。对有背景依据的第1、2、13关修正位置与贴图，其余关卡以视觉比例、轻微角度和接触阴影改善，不随机移动谜题坐标。方向线索、角色与安装件保持正向。

真实贴图仍由 `PropArtRects` 的主体边界切出，保留 `packable=false`；视觉变化与命中区分离。第13关积水使用低矮半透明水面，避免竖水滴看起来悬浮。阴影不用于悬挂件、光束、印记等元素。

- `npm run typecheck`：Creator实际类型声明下的strict检查。
- `npm test`：框架、存档、计时、美术、归档，以及80关1134种可达状态；新增陈设验证检查边界、来源/目标中心遮挡、旋转范围与旧存档兼容。
- `npm run build:web`：重新构建Creator 3.8.7产物，并执行发布隔离检查。
- `npm run test:runtime`：在本次构建中以真实指针完成80关459步；逐关检查实际文字字号、按钮边角与深色文案。另验证提示、超时、撤销、键盘、存档异常及直接Home/Game入口。
- 视口：640×1386、320×568、390×844、960×540；小屏与横屏实际点击暂停、提示、返回案卷与打开关卡。横屏仍采用整体等比容纳，没有单独制作横屏布局；浏览器检查不等于手机真机验收。

本机结果位于 `build/cat-detective-validation/result.json`。`home.png`、`case-list.png`、`hint-dialog.png`、`timeout-dialog.png` 与 `viewport-*.png` 为本次实际画面；`case-1-start.png` 至 `case-80-start.png` 为全部关卡，`review-01.png` 至 `review-10.png` 为每页8关的陈设检视图。生成目录不提交Git。
