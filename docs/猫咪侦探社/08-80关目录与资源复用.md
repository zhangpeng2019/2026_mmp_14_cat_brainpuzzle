# 猫咪侦探社：80关目录与资源复用

当前正式数据共 **80 个可玩案件、459 个有效步骤、740 个场景对象定义**。对象定义包含前后状态和结案印章，不等同于独立贴图数量。

原版87关位于 `archive/legacy-brainpuzzle/`，未计入本目录，也不参与正式构建。糖果卡通版使用12张场景、10张160格透明道具图集和3张UI美术图；提供点击、拖动、滑动、长按和擦拭，按关卡安排180—360秒限时。场景不绘制道具姓名标签。
