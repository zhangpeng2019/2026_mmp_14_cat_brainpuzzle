## 本次修复

- 原 UI 层级接入框架 UIManager，资源加载接入 ResourceLoader，存档接入 DataStore。
- 保留关卡包配置，修复跨包共享资源在 LRU 释放及并发预加载时丢失。
- Game 相机包含原资源使用的层，near=0，兼容原 UI 的 z=1000。
- 返回入口前清理游戏状态、UI 和计时器；音频单例在重新进入时重建有效节点，销毁弹窗时跳过已销毁的触摸节点。
- 关卡卸载时关闭共享物理模拟，物理关启动时再开启，避免绳索关卸载后空 Box2D 世界继续步进异常。
- 第 1/3 关触摸增量按原坐标比例转换；右上角返回入口随 Canvas 尺寸对齐。
